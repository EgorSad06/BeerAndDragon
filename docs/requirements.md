# Спецификация требований BeerAndDragon — версия 0.1

| | |
|---|---|
| Версия | 0.1 (черновик для первой итерации) |
| Продукт | BeerAndDragon — однопользовательский шутер от первого лица на Unity 6 (6000.3.0f1, URP) |
| Платформа | Windows 10/11 x64 (поставка), Linux x64 (только headless-запуск в CI) |
| Связанные документы | [MVP](mvp.md) · [исходное состояние](environment.md) · [правила репозитория](repo-rules.md) · [CI](CI.md) |

## 1. Назначение продукта
Динамичный шутер в духе ULTRAKILL: быстрое передвижение (скольжение, бег по стенам), дробовик и меч ближнего боя,
но в средневековом сеттинге и с юмором: рыцарь лечится сигаретами, ускоряется энергетиком и катается на скейте
с трюками в стиле Tony Hawk's Pro Skater. Цель версии 0.1 — играбельный уровень-песочница, на котором работает
весь основной цикл: передвижение → бой → подбор и использование предметов → смерть/перезапуск.

## 2. Пользователи
| Роль | Кто это | Что им нужно |
|---|---|---|
| **Игрок** | любитель «бумер-шутеров» и скейт-игр, играет с клавиатуры и мыши | отзывчивое управление, понятный HUD, быстрый перезапуск после смерти |
| **Разработчик / тестировщик** | участники команды, преподаватель | сборка из чистого репозитория, автотесты, журнал работы игры для разбора ошибок |
| **CI** | GitHub Actions | запуск игры без графики, машиночитаемый отчёт, код возврата 0/1 |

## 3. Основной сценарий (MVP)
1. Игрок запускает игру → загружается уровень `SampleScene`, на HUD видны здоровье и пояс-хотбар.
2. Игрок перемещается по уровню: бег, прыжок, приседание, скольжение, бег по стенам.
3. Игрок подбирает дробовик/меч и коробки патронов, стреляет по мишеням, перезаряжается.
4. Игрок получает урон (зона урона), подбирает сигареты и лечится; пьёт энергетик и ускоряется.
5. Игрок встаёт на скейт, разгоняется, делает трюки, получает очки.
6. При нулевом здоровье игрок погибает → уровень перезапускается.

## 4. Ошибки и нештатные ситуации
| ID | Ситуация | Требуемое поведение |
|---|---|---|
| ERR-01 | Использование лечения при полном здоровье | предмет **не** тратится, на HUD сообщение «Здоровье и так полное» |
| ERR-02 | Подбор предмета при полном инвентаре | подбирается сколько влезает, остаток остаётся лежать на уровне |
| ERR-03 | Выстрел с пустым магазином | выстрела нет; если есть запас — автоматическая перезарядка |
| ERR-04 | Коробка патронов при полном запасе | коробка не подбирается и не исчезает |
| ERR-05 | Неудачное приземление на скейте (боком, недокрученный флип, лобовой удар о стену) | бэйл: игрок слезает со скейта, комбо сгорает, игра продолжается |
| ERR-06 | Исключение в игровом коде | ошибка со стеком пишется в журнал (`[ERROR]`), игра не закрывается |
| ERR-07 | Ошибка при CI-запуске (`-ciSmoke`) | отчёт `ok: false`, код возврата 1 |
| ERR-08 | Повторный возврат объекта в пул (ошибка программиста) | `InvalidOperationException` сразу в месте ошибки |

## 5. Функциональные требования
Формат критерия: **условия → действие → ожидаемый результат**. Колонка «Проверка»: `T` — автотест (EditMode),
`M` — ручная проверка в игре, `CI` — проверка в конвейере.

### 5.1 Передвижение
| ID | Требование | Критерий проверки | Проверка |
|---|---|---|---|
| FR-MOV-01 | Ходьба и прыжок | игрок стоит на земле → нажать `W`, затем `Space` → движется вперёд и подпрыгивает; в воздухе повторный прыжок не срабатывает | M |
| FR-MOV-02 | Скольжение | игрок бежит → нажать `LeftShift` → короткий рывок-скольжение, затем перезарядка способности | M |
| FR-MOV-03 | Приседание | игрок на земле → удерживать `LeftControl` → рост и скорость уменьшаются | M |
| FR-MOV-04 | Камера | игра запущена → нажать `V` → вид переключается между 1-м и 3-м лицом | M |

### 5.2 Оружие
| ID | Требование | Критерий проверки | Проверка |
|---|---|---|---|
| FR-WPN-01 | Дробовик стреляет пачкой дробин в конусе | конус разброса 0° → выстрел → все дробины летят строго вперёд; конус N° → каждая дробина отклонена не больше чем на N° и не все совпадают | T `WeaponTests.SpreadDirection_*` |
| FR-WPN-02 | Урон падает с дистанцией | `falloffStart=6`, `falloffEnd=25` → попадание с 6 м и ближе → полный урон; дальше 25 м → минимальный; между — убывает монотонно; некорректный диапазон → без падения | T `WeaponTests.Falloff*` |
| FR-WPN-03 | Магазин и перезарядка | в магазине 2 патрона, в запасе > 0 → 2 выстрела, затем `R` (или автоматически) → магазин снова 2, запас уменьшился на 2 | M |
| FR-WPN-04 | Предел запаса патронов | запас 36 из 40 → подобрать коробку на 8 → запас 40, коробка взяла только 4 | T `WeaponTests.AddAmmo_RespectsMaxReserve` |
| FR-WPN-05 | Дырки от пуль | выстрел в стену → в точке попадания появляется декаль, старые исчезают при превышении лимита | M |
| FR-WPN-06 | Меч | меч в руках → `ЛКМ` → взмах, мишень в зоне удара получает 50 урона | M |
| FR-WPN-07 | Переключение оружия | в хотбаре дробовик и меч → нажать их клавиши → в руках соответствующее оружие | M |

### 5.3 Здоровье
| ID | Требование | Критерий проверки | Проверка |
|---|---|---|---|
| FR-HP-01 | Начальное здоровье | старт уровня → здоровье = 100 из 100 | T `PlayerHealthTests.StartsWithMaxHealth` |
| FR-HP-02 | Получение урона | здоровье 100 → урон 30 → 70; урон ≤ 0 → без изменений | T `PlayerHealthTests.TakeDamage_*` |

## 6. Нефункциональные требования
| ID | Требование | Критерий проверки | Проверка |
|---|---|---|---|
| NFR-01 | Время запуска | чистая установка, headless-запуск → сцена загружена быстрее 30 с | CI `release.yml` (`MAX_STARTUP_SECONDS`) |
| NFR-02 | Стабильность | 10 с headless-игры → 0 ошибок в журнале | CI `release.yml` (`MAX_ERRORS=0`) |
| NFR-03 | Воспроизводимая сборка | чистый checkout тега → сборка той же версией Unity (`ProjectVersion.txt`) и пакетами (`packages-lock.json`) | CI `main.yml`, `release.yml` |
| NFR-04 | Целостность поставки | скачанный архив → `sha256sum -c SHA256SUMS.txt` → OK | CI `release.yml` |
| NFR-05 | Нет секретов в репозитории | любой коммит → gitleaks не находит токенов/паролей | CI `_checks.yml` |
| NFR-06 | Состав поставки известен | релиз → `sbom.cdx.json` (CycloneDX) со всеми пакетами и сторонними ассетами | CI `release.yml` |
| NFR-07 | Нет аллокаций в горячем пути пула | пул прогрет → 100 циклов Get/Release → 0 байт в управляемой куче | T `BoundedPoolTests.SteadyState_GetRelease_DoesNotAllocate` |
| NFR-08 | Производительность | обычный ПК (GTX 1060 / 8 ГБ ОЗУ), 1080p → ≥ 60 FPS на `SampleScene` | M (`-diag`, FPS в журнале) |
| NFR-09 | Качество тестов | засеянный дефект из `ci/mutations.json` → хотя бы один тест падает | CI `pz-checks.yml → mutation` |
| NFR-10 | Сборка игры не зависит от редактора | код в `Scripts/` не использует `UnityEditor` без `#if UNITY_EDITOR` | CI `lint_cs.py` (E001) |
