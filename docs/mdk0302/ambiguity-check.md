# Проверка однозначности требований участка «Оружие и попадания» (Р7)

**Как проводить.**
1. Проверяющий получает только текст раздела 5.2 спецификации ([requirements.md](../requirements.md)) и таблицу ситуаций ниже.
   Раздел «Ключ» ему не показывают.
2. По тексту требований он записывает ожидаемый исход каждой ситуации.
3. Ответы сверяются с ключом. Совпадение подтверждает однозначность; расхождение — повод уточнить требование.
   После уточнения ситуацию задают снова.

Проверяющий: <имя / роль> (проект одиночный; методичка: студент другого проекта или преподаватель —
<кто проверял, по чьему назначению>). Дата: <дата>. Версия текста: <commit>.

## Ситуации
| № | Ситуация | Ответ проверяющего |
|---|---|---|
| С1 | В магазине 1 патрон, в запасе 10. Игрок нажимает `ЛКМ`. Что будет с магазином и запасом сразу после выстрела и через 1 секунду? | |
| С2 | Магазин 0, запас 0. Игрок нажимает `ЛКМ`, затем `R`. Что увидит и услышит игрок, изменятся ли счётчики? | |
| С3 | Запас 38 из 40, игрок наступает на коробку с 8 патронами. Сколько станет в запасе, что будет с коробкой? | |
| С4 | На уровне уже 60 дырок. Дробина попадает в стену. Сколько дырок станет и какая исчезнет? | |
| С5 | Дробина попадает в ящик, который можно толкнуть (с физикой). Появится ли дырка, получит ли ящик урон? | |
| С6 | Игрок стреляет в стену, сразу берёт меч и 20 секунд ходит с ним. Останется ли дырка? | |
| С7 | В `game-config.json` записано `"decalPool": "fast"`. Что произойдёт при запуске? | |

## Ключ (замысел автора)
| № | Ожидаемый исход | Требование |
|---|---|---|
| С1 | Сразу: магазин 0, запас 10. Перезарядка начинается сама, через 0,9 с: магазин 2, запас 8 | FR-WPN-01, FR-WPN-03 |
| С2 | `ЛКМ`: выстрела нет, щелчок пустого оружия; `R`: ничего не происходит; счётчики не меняются, `0` и `/ 0` красным | FR-WPN-03.1 |
| С3 | Запас 40; в коробке остаётся 6, коробка лежит дальше | FR-WPN-04 |
| С4 | Дырок по-прежнему 60: переставляется самая давно поставленная | FR-WPN-05 |
| С5 | Дырки нет, урон проходит | FR-WPN-05.1 |
| С6 | Дырка остаётся: время жизни идёт, только пока дробовик в руках | FR-WPN-05 (после уточнения ОП-1) |
| С7 | `[ERROR][Config] … decalPool = fast -- ожидается "bounded" или "linked"`, игра завершается с кодом 2 | FR-WPN-05.1 |
