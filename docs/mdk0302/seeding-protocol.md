проектировании классов эквивалентности параметр `oneByOne` взят только в значении сцены. Тот же пробел показал отчёт
покрытия — строка 110 (`else nextLoadAt += ReloadTime;`) не выполнялась (рисунок 3). Набор дополнен тестами
T37 (по патрону за интервал), T38 (прерывание и запас 1), T39 (долгий кадр 2 с — должны зарядиться оба патрона).
D9 обнаруживает только T39: при обычной частоте кадров ошибка не видна, она проявляется после просадки.

**Естественные дефекты**, найденные набором при разработке тестов: **0** — на исправном коде все тесты прошли с первого
прогона (прогон 0). При проектировании проверок найден дефект **требований**, а не кода: для ошибочных данных
(коробка ≤ 0, неверные настройки оружия) в спецификации 1.0 не было ожидаемого результата → добавлено FR-WPN-04.1
(спецификация 1.1) и обработка неверных настроек в `Weapon`. Дефект кода «нет звука щелчка» найден раньше, в ПЗ-1
проверкой однозначности, а не этим набором — в подсчёт не входит.

**Оценка по Миллсу.** N = S·n / s, где S — засеяно, s — обнаружено засеянных, n — естественных. Для набора v2:
S = 10, s = 10, n = 0 → оценка числа исходных дефектов 0. Оценка слабая: засеянные дефекты придуманы автором набора,
поэтому похожи на то, что набор уже умеет ловить, а n = 0 не даёт статистики. Связку `Weapon` ↔ `AmmoMagazine`
засев не проверял (риск R5 — ручные проверки М1–М6).
