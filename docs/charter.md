## Пользователь и проблема
**Пользователь** — игрок на ПК, который любит быстрые «бумер-шутеры» (ULTRAKILL, DOOM, Quake) и играет короткими сессиями по 10–30 минут.

**Проблема** *(сформулирована автором, подтверждается обследованием — [survey.md](mdk0302/survey.md))*:
- быстрые шутеры требуют освоить много механик и серьёзно настроены;
- лёгких, смешных по сеттингу игр, где можно сразу «пострелять и покататься», мало;
- без продукта игрок запускает большую игру ради короткой сессии и тратит время на вход и меню.

## Ожидаемый результат
Игрок запускает игру и без меню сразу попадает на уровень-песочницу. Там он:
- бегает, скользит и бегает по стенам;
- стреляет из дробовика и рубит мечом;
- подбирает и применяет предметы (сигареты лечат, энергетик ускоряет);
- катается на скейте с трюками.

После смерти уровень перезапускается за секунды.

## Собственная логика
Готовые решения: движок Unity, физика PhysX, рендер URP. Правила игры — собственный код проекта:

| Правило | Где |
|---|---|
| **Дробь и урон:** 12 дробин в конусе разброса, урон убывает с дистанцией от 100 % до 25 %, магазин и запас с лимитом | `Weapon` (`SpreadDirection`, `FalloffMultiplier`, `AddAmmo`) |
| **Инвентарь:** стопки до `maxStack`, сначала дополняются неполные, остаток возвращается; обмен и слияние ячеек | `Inventory` |
| **Пул декалей:** не больше N дырок; при переполнении переставляется самая старая; время жизни | `IObjectPool` / `BulletHoles` |
| **Скейт:** оценка приземления (PERFECT / SKETCHY / падение), убывание очков за повтор трюка, спец-шкала | `SkaterController` |
| **Конфигурация:** явная проверка значений, ошибка → код 2 | `GameConfig` |

## Модуль для эксперимента и внешний ресурс
- **Модуль для наблюдения и измерения** — пул декалей `ObjectPool` с потребителем `BulletHoles`.
  Воспроизводимый вход: `-decalProbe N`; две реализации переключаются конфигурацией. Подробно — в [ADR-002](adr/ADR-002-decal-pool.md).
- **Внешние ресурсы:**
  - файл конфигурации `game-config.json`;
  - журнал в `%USERPROFILE%\AppData\LocalLow\…\logs`;
  - видеокарта и звук (через Unity);
  - сеть и БД не используются.

## Ограничения
| Ограничение | Следствие |
|---|---|
| Один разработчик, учебный срок (семестр) | MVP — один уровень; враги, меню, сохранения — в резерве ([mvp.md](mvp.md)) |
| Нужна лицензия Unity Personal и версия редактора 6000.3.0f1 | Секреты лицензии — только в GitHub Secrets; версия зафиксирована |
| Сторонние ассеты (модели, звуки) | Хранятся в Git LFS; звуки Jet Set Radio — только для учебного прототипа |
| Поставка — Windows x64; CI — Linux без графики | Графика и ввод проверяются вручную |
| Опыт: C# и Unity есть, C++ и низкоуровневой графики нет | Стек — Unity/C# (ADR-001) |
