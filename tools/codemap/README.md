# CodeMap — живая карта кода BeerAndDragon

Локальное веб-приложение: граф классов и файлов проекта, их связи, сцены и префабы, статистика.
Обновляется само, пока ты пишешь код.

## Запуск
- двойной клик по `codemap.cmd` в корне проекта, **или**
- `node tools/codemap/server.js --open`

Откроется `http://localhost:5177`. Нужен только Node.js 18+, без `npm install`.
Для подсветки замечаний линтера нужен Python (используется `ci/lint_cs.py`), для git-статусов — git.

Параметры: `--port 5178`, `--root <путь к Unity-проекту>`, `--open` (открыть браузер).

## Что показывает
**Граф** — узлы: классы, интерфейсы, enum'ы, тесты, editor-инструменты, сцены, префабы и ассеты данных.
Размер узла = строки кода, форма: ● класс, ⬢ static/editor, ◆ интерфейс, ■ сцена/префаб/ассет.

| Связь | Откуда берётся |
|---|---|
| использует | упоминание типа в коде (поле, параметр, вызов) |
| GetComponent / Find | `GetComponent<T>`, `AddComponent<T>`, `Find*ObjectByType<T>`, `[RequireComponent]` |
| подписка на событие | `x.SomeEvent += ...`, где событие объявлено в другом классе |
| наследует / реализует | базовый класс / интерфейс из проекта |
| тестирует | тестовый класс упоминает или создаёт этот класс |
| на сцене / в префабе | `m_Script` с GUID скрипта в `.unity` / `.prefab` / `.asset` |

**Цвет**: папка, тип, сложность (ветвления), размер, тесты (есть/нет), git (новый/изменён/как часто правят), lint.

**Карточка класса** (клик по узлу): метрики, Unity-колбэки, методы с полоской сложности, поля (◆ — видно в инспекторе),
свойства, события, связи в обе стороны, замечания линтера, просмотр кода с подсветкой и переходом по типам, ссылка «открыть в VS Code».

**Статистика**: строки по папкам, виды типов, самые сложные классы, хабы (от кого зависят больше всего),
покрытие тестами как диагностика + самые сложные классы без тестов, длинные методы, Unity-колбэки,
«возможно не используются», горячие файлы git, динамика за сессию.

**Живое обновление**: сервер следит за `Assets/**` (`.cs`, сцены, префабы, ассеты), `ci/*.py` и `.git/index`.
Сохранил файл — граф перестраивается, изменённые узлы пульсируют, всплывает уведомление «+6 стр, +1 метод»,
событие попадает в ленту (кнопка ☰).

## Управление
Колесо — масштаб · перетаскивание фона — сдвиг · перетаскивание узла — двигать (Shift — закрепить) ·
клик — детали · двойной клик — приблизить · `/` — поиск (классы, методы, файлы) · `F` — показать всё ·
`Space` — заморозить раскладку · `1`/`2` — граф/статистика · `Esc` — сброс.

## Как устроено
- `scanner.js` — разбор C# без компилятора: удаляет комментарии и строки, находит типы и члены по скобкам и регуляркам,
  строит связи; читает GUID из `.meta` и ссылки на скрипты в YAML-ассетах; берёт `git status` / `git log` и вывод линтера.
- `server.js` — HTTP + Server-Sent Events, `fs.watch` с дебаунсом, diff между сканами. Слушает только `127.0.0.1`,
  отдаёт исходники только из папки проекта.
- `public/app.js` — force-directed раскладка и отрисовка на canvas без библиотек, всё остальное — обычный DOM.
